# imgConvert

A simple, lightweight batch image converter. Converts `.jpe`, `.jpg`, and `.png` images between formats with zero hassle.

You can run this project in two ways:
1. **Desktop GUI App (`gui_app.py`)** – A clean desktop window with browse buttons and progress bar (can also be compiled into a standalone Windows `.exe`).
2. **Terminal Script (`main.py`)** – The original lightweight command-line script.
